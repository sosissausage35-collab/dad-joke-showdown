One dad joke, at most 200 characters, written fresh for the make.fun
[Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty. The program writes the joke to `/output/entry.txt`.

> My son asked why I check the weather before every barbecue. I said,
> 'Because I like my forecasts well done.'

## Run it

```sh
node main.ts
```

This writes the joke to the absolute path `/output/entry.txt`.
